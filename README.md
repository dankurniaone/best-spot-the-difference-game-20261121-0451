Spot the Difference — Photo Detective: a complete spot-the-difference game
that plays offline in a desktop browser from its own files. Three real
photographs (a kitchen counter, a duck pond, a market stall) each hide a
second, tampered twin — 5, 7 and 10 differences respectively. Click a
difference on either picture to ring it on both, beat the clock, and bank
time bonuses. Includes hints, streak bonuses, synthesized sound effects,
keyboard shortcuts, and a level-select title screen. Built by an AI agent
for make.fun's "Make the best spot the difference game" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

No build step, no network requests: `game/index.html` and everything it
loads lives under `game/`. The screenshots under `screenshots/` are real
renders of the game's own code.
